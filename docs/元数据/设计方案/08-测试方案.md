## 1. 测试策略

### 1.1 测试框架

| 层级 | 框架 | 用途 |
|------|------|------|
| 单元测试 | Go 标准库 `testing` | Filter / CEL / Repository 等核心逻辑 |
| 断言库 | `github.com/stretchr/testify/assert` | 断言 |
| Mock | `github.com/stretchr/testify/mock` | 接口 Mock |
| 静态 API | GoFrame `gtest` + 标准 Controller | `/api/meta/*`，走 `g.Meta` 与响应中间件 |
| 动态 CRUD HTTP | `httptest` 或 `gtest` | `/api/c/:collection`，不按表 codegen |
| 数据库测试 | Docker MySQL 8（root/123456，库 itcodex） | 与本机开发环境一致 |
| 覆盖率 | `go test -cover` | 代码覆盖率统计 |

`internal/dao`、`internal/model/do`、`internal/model/entity` 由 `gf gen dao` 生成，**不为其手写单测、不手改后再测**。测的是 service 对 dao 的调用与业务 Repository。

### 1.2 测试层级

```
┌─────────────────────────────────────────────┐
│            E2E/集成测试 (5%)                │  启动完整HTTP服务，API端到端测试
├─────────────────────────────────────────────┤
│            集成测试 (25%)                    │  多模块协作、数据库真实操作、Yaegi脚本执行
├─────────────────────────────────────────────┤
│            单元测试 (70%)                    │  单个模块/函数独立测试，Mock依赖
└─────────────────────────────────────────────┘
```

### 1.3 覆盖率目标

| 模块 | 目标覆盖率 | 优先级 |
|------|-----------|--------|
| CEL校验引擎 | ≥ 90% | P0 |
| Filter解析/Operator | ≥ 90% | P0 |
| Repository CRUD | ≥ 85% | P0 |
| Collection/Field管理 | ≥ 80% | P0 |
| Yaegi脚本执行 | ≥ 75% | P1 |
| HTTP Controller | ≥ 70% | P1 |
| 整体 | ≥ 80% | - |

### 1.4 测试文件命名约定

- 测试文件与源文件同目录，命名为 `xxx_test.go`
- 测试函数命名：`TestXxx(t *testing.T)`
- 子测试使用 `t.Run("场景描述", func(t *testing.T) { ... })`
- 基准测试：`BenchmarkXxx(b *testing.B)`

package testutil

// Assert 快捷断言入口
var Assert = assert.New

// NewTestDatabase 创建测试数据库（Docker MySQL）
func NewTestDatabase(t *testing.T) *metadata.Database {
    t.Helper()
    // 使用本机 Docker MySQL，测试结束清理连接
    db, err := metadata.NewDatabase(metadata.DatabaseOptions{
        DSN:         "root:123456@tcp(127.0.0.1:3306)/itcodex?parseTime=true&loc=Local",
        TablePrefix: "test_",
        Logging:     false,       // 测试时关闭日志（失败时可开启）
    })
    if err != nil {
        t.Fatalf("创建测试数据库失败: %v", err)
    }
    if err := db.Bootstrap(); err != nil {
        t.Fatalf("启动元数据模块失败: %v", err)
    }
    t.Cleanup(func() {
        db.Close()
    })
    return db
}

// CreateTestCollection 快速创建测试用Collection
func CreateTestCollection(t *testing.T, db *metadata.Database, name string) *metadata.Collection {
    t.Helper()
    coll, err := db.CreateCollection(context.Background(), metadata.CreateCollectionInput{
        Name:        name,
        DisplayName: name + "_display",
        Type:        metadata.CollectionTypeGeneral,
        PresetFields: []string{"id", "createdAt", "updatedAt"},
        Fields: []metadata.CreateFieldInput{
            {
                Name:        "title",
                Type:        "string",
                DisplayName: "标题",
                IsRequired:  true,
                Options: map[string]any{
                    "maxLength": 200,
                },
            },
            {
                Name:        "age",
                Type:        "integer",
                DisplayName: "年龄",
                IsRequired:  false,
                Validation: &metadata.FieldValidationConfig{
                    Min: intPtr(0),
                    Max: intPtr(150),
                },
            },
            {
                Name:        "status",
                Type:        "select",
                DisplayName: "状态",
                Options: map[string]any{

                    "default": "draft",
                },
            },
        },
    })
    if err != nil {
        t.Fatalf("创建测试Collection失败: %v", err)
    }
    return coll
}

func TestDatabase_RegisterOperator(t *testing.T) {
    db := testutil.NewTestDatabase(t)
    a := testutil.Assert(t)

    t.Run("注册并使用自定义操作符", func(t *testing.T) {
        // 注册 $even 操作符（判断偶数）
        db.RegisterOperator("$even", func(col string, val any, params *[]any) string {
            *params = append(*params, 0)
            return fmt.Sprintf("(%s %% 2) = ?", col)
        })

        coll := testutil.CreateTestCollection(t, db, "test_op")
        repo := coll.Repository()

        // 创建测试数据
        for i := 1; i <= 4; i++ {
            repo.Create(context.Background(), &CreateOptions{
                Values: map[string]any{
                    "title": fmt.Sprintf("item%d", i),
                    "age":   i,
                },
            })
        }

        // 使用自定义操作符查询偶数
        list, err := repo.Find(context.Background(), &FindOptions{
            Filter: Filter{"age": map[string]any{"$even": true}},
        })
        a.NoError(err)
        a.Len(list, 2) // 2,4 是偶数
    })
}

func TestRepository_Find(t *testing.T) {

            a.Contains([]int{20, 30}, age)
        }
    })

        list, err := repo.Find(context.Background(), &FindOptions{
            Filter: Filter{"title": map[string]any{"$like": "%测试%"}},
        })
        a.NoError(err)
        a.NotEmpty(list)
    })

    t.Run("AND组合条件", func(t *testing.T) {
        list, err := repo.Find(context.Background(), &FindOptions{
            Filter: Filter{
                "$and": []Filter{
                    {"status": "published"},
                    {"age": map[string]any{"$gte": 25}},
                },
            },
        })
        a.NoError(err)
        for _, r := range list {
            a.Equal("published", r.Get("status"))
            a.GreaterOrEqual(r.Get("age").(int), 25)
        }

            Filter: Filter{

```yaml
# .github/workflows/test.yml 示例
steps:
  - name: 运行单元测试
    run: go test ./... -v -coverprofile=coverage.out -race

  - name: 检查覆盖率
    run: |
      go tool cover -func=coverage.out | tail -1
      # 要求总体覆盖率 ≥ 80%

  - name: 运行竞态检测
    run: go test ./... -race

  - name: 基准测试对比
    run: |
      go test ./... -bench=. -benchmem -run=^$ > bench_new.txt
      # 与基准对比，性能不下降超过10%
```

## 8. 测试数据策略

| 场景 | 数据策略 |
|------|----------|
| 单元测试 | 使用内存数据库，每个测试独立，t.Cleanup清理 |
| 集成测试 | 内存数据库或临时文件，测试结束删除 |
| 字段类型测试 | 边界值（0、空串、最大长度、null、负数） |
| 校验测试 | 合法值、边界值、非法值都要覆盖 |
| 并发测试 | 多goroutine同时创建/查询，验证线程安全 |
| Yaegi测试 | 正常脚本、语法错误脚本、运行时panic脚本 |
