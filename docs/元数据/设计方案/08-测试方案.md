## 1. 测试策略

### 1.1 分层

| 层级 | 位置 | 框架 | 职责 |
|------|------|------|------|
| 单元 / 服务集成 | `server/internal/service/metadata/*_test.go` | `testing` + testify | Filter / CEL / Repository / 关系 / Yaegi / 系统表 dao |
| HTTP E2E | `client/internal/tests/` | net/http + testify | 真实服务 + MySQL，验证契约与联通性 |
| 生成代码 | `internal/dao` / `do` / `entity` | — | **不单测、不手改** |

### 1.2 环境

| 项 | 值 |
|----|-----|
| MySQL | Docker `root`/`123456`，库 `itcodex` |
| 服务 | `cd server && go run .` → `:8000` |
| E2E 地址 | `TEST_SERVER_URL`（默认 `http://127.0.0.1:8000`） |
| 系统表前缀 | 生产/E2E：`c_`（走 dao）；服务端单测：随机前缀（走 `database/sql`） |

### 1.3 覆盖率目标（服务端）

| 模块 | 目标 | 优先级 |
|------|------|--------|
| Filter / Operator | ≥ 90% | P0 |
| Repository CRUD + 工作单元 | ≥ 85% | P0 |
| CEL | ≥ 85% | P0 |
| 关系 / 嵌套写入 / onDelete | ≥ 80% | P0 |
| Yaegi 钩子 / validate | ≥ 75% | P1 |
| JWT / ResourceManager / ACL | ≥ 85% | P0 |

## 4. 错误码约定（E2E 断言）

| code / HTTP | 含义 |
|-------------|------|
| 0 / 200\|201 | 成功 |
| 404 | 资源不存在 |
| 409 | 重名冲突 |
| 422 | 校验失败（`data.fieldErrors` / `tableErrors`） |
| 403 | 禁止无条件清空、删除有依赖且未 cascade |

## 5. 优先级

1. **P0**：CRUD / Filter / 校验 / 嵌套关联 / 工作单元 / Collection cascade  
2. **P1**：Yaegi validate/toggle / Index / 特殊表与上传  
3. **P2**：基准、并发、HTML 报告  

## 6. 明确不测

- `$col` / `$exists` / 日期族 / 数组族 Filter（设计不做）  
- 页面 / 工作流 / SSO / 多数据源 ACL
- 云对象存储（仅本地 `storagePath`）  
- `gf gen dao` 生成文件本身  

## 7. 安全回归

- JWT 登录、过期、refresh 一次性轮换、登出撤销
- 默认拒绝、角色通配、多角色行范围 OR、固定范围 AND
- 读写字段限制及 filter/sort/appends 越权拒绝
- 关联读取、绑定、替换、解绑均验证源和目标资源
- Meta、Yaegi Script 与 custom API 匿名访问拒绝
- `X-Actor-Id` 不再影响 `created_by/updated_by`
