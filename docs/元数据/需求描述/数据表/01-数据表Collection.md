# 数据表（Collection）

> 来源：https://docs.nocobase.com/cn/data-sources/data-modeling/collection
> 整理时间：2026-09-02

## 介绍

在 NocoBase 中，**Collection（数据表）** 是用来描述一类业务数据的数据模型。它不是单纯的数据库表名，而是 NocoBase 对一类数据的统一描述。

一个 Collection 通常定义三件事：

| 定义 | 说明 |
|------|------|
| 数据保存在哪里 | 数据可以来自主数据库表、外部数据库表、SQL 查询结果、数据库视图、REST API 资源或外部 NocoBase 应用。 |
| 有哪些字段 | 字段描述每条记录有哪些信息，比如客户名称、手机号、订单金额、创建时间、负责人。 |
| 如何被 NocoBase 使用 | 页面区块、权限、工作流、API 和关系字段都会基于 Collection 工作。 |

你可以把 Collection 理解为"业务对象的数据结构"。比如「客户」「订单」「合同」「任务」都可以是一个 Collection。

数据表创建或接入后，通常还需要继续做三件事：

* 配置字段，让数据表能保存业务需要的信息
* 在页面中添加区块，让用户可以查看、录入和处理数据
* 配置权限、工作流和 API，让数据可以按业务规则被访问和流转

## 表结构类型

* **普通表** — 适合保存客户、订单、合同、工单、报销单、项目、任务等常规业务数据
* **树表** — 适合保存组织架构、商品分类、地区层级、部门目录、知识库目录等上下级数据
* **日历表** — 适合保存会议室预约、项目排期、课程安排、值班计划、活动日程等带时间范围的数据
* **评论表** — 适合保存任务评论、文章评论、审批意见、客户反馈等围绕业务记录产生的讨论内容；在业务表（普通表、树表、日历表）中创建关系字段关联评论表，使用业务表弹窗页面创建评论区块，对业务数据进行评论
* **文件表** — 适合保存合同附件、发票文件、产品图片、员工证件等文件元信息，文件实际由文件存储引擎保存；在业务表（普通表、树表、日历表）中创建关系字段关联文件表，使用业务表创建区块配置关系字段上传文件，文件元信息会自动保存到文件表中
* **数据库视图** — 数据库里已有的 view，比如财务报表视图、过滤后的客户视图、跨系统同步后的聚合视图
* **SQL 表** — 适合把销售汇总、库存预警、跨表统计报表、运营看板等 SQL 查询结果作为数据表使用
* **继承表** — 多类业务对象共享一组公共字段，同时每一类又有自己的专属字段，比如资产父表派生电脑资产、车辆资产、办公家具

## 补充：各类表结构说明

### 普通表

普通表是最常用的表类型，内置了常用的系统字段（如ID、创建时间、更新时间、创建人、更新人等），适合大多数业务场景。

### SQL 表

编写 SQL 查询语句形成 SQL 表，不会在数据库创建真实数据库表，是读取 SQL 查询结果，让查询结果可以在表格、详情、图表和工作流中使用。

**注意**：SQL 表只支持 `SELECT` 语句或 `WITH ... SELECT` 语句，默认只支持数据查询展示，社区版+支持数据的新增、编辑和删除。

**配置项**：

| 配置 | 说明 |
|------|------|
| Collection display name | SQL 表在界面中显示的名称，比如「销售汇总」「库存预警」 |
| Collection name | SQL 表在 NocoBase 中的标识名称，用于 API、关系字段、权限、工作流等内部引用 |
| Categories | 数据表分类，只影响数据表管理界面的组织方式 |
| Description | 数据表说明，建议写清楚查询内容、维护人、使用场景 |
| Record unique key | 记录唯一标识，需要选择一个能唯一定位记录的字段或字段组合 |
| SQL | SQL 查询语句 |
| Source collections | SQL 查询结果的字段来源数据表 |
| Fields | 字段映射配置，确认每个字段的名称、来源、界面类型和显示名称 |

### 继承表

可以创建一个父表，然后从该父表派生出子表，子表会继承父表的结构，同时还可以定义自己的专属字段。适用于多类业务对象共享公共字段的场景。

### 树表

树结构表，目前只支持邻接表设计，用于表示具有层级关系的数据。

### 日历表

用于创建日历相关的事件表，适合带时间范围的数据展示和管理。

### 文件表

用于文件存储的管理，保存文件元信息，文件实际由文件存储引擎保存。

### 数据库视图（视图表）

连接已有的数据库视图，将数据库中已存在的 view 作为数据表使用。

### 外部表

允许数据库系统直接访问和查询外部数据源中的数据，基于 FDW（Foreign Data Wrapper）技术。

## 创建数据表的基本步骤

1. 进入管理后台
2. 点击"设置" → "数据源" → 选择数据源 → "Configure"
3. 点击"Create collection"，选择表类型
4. 配置表基本信息（显示名称、标识名称、分类、描述等）
5. 添加字段（名称、类型、配置）
6. 保存并配置字段映射（如需要）
7. 在页面中添加区块使用该数据表
