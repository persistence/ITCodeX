# 表选择器（Collection select）

> 来源：NocoBase 文档整理
> 整理时间：2026-09-02

## 介绍

在 NocoBase 中，**表选择器（Collection select）** 属于高级类型字段，用于让用户选择关联到哪个数据表。

表选择器字段存储的数据表标识（collection name），常用于动态关联、多态关联场景，比如评论可以关联订单、文章、商品等不同表，附件可以关联到任意表，通用的备注、日志、审批记录可以挂在任意数据下。

表选择器通常配合多态关联字段使用，实现"一个字段可以关联任意表"的需求。

## 适用场景

表选择器适合这些业务场景：

* 多态关联：评论、点赞、收藏、附件、操作日志可以关联到任意类型的业务数据
* 通用模块：审批流、评论、通知、标签系统等通用功能，需要关联到任意业务表
* 动态配置：区块配置、表单配置中选择关联的数据表
* 跨模块引用：通用功能需要知道当前记录属于哪个表

## 创建配置

在数据表的「Configure fields」页面中，点击「Add field」，在高级类型中选择「表选择器」可以创建表选择器字段。

| 配置 | 说明 |
|------|------|
| Field interface | 字段的界面类型。表选择器对应 collectionSelect，以下拉框选择数据表。 |
| Field display name | 字段在界面中显示的名称，比如「关联表」「数据类型」「所属模块」。 |
| Field name | 字段标识名称，用于 API、权限、工作流等内部引用。创建后通常不再修改。 |
| Field type | 字段在数据层的类型。通常是字符串类型，存储数据表的 name 标识。 |
| Available collections | 可选的数据表范围，可以限制哪些表可以被选择，默认可以选择所有表。 |
| Allow create new | 是否允许在选择时新建数据表（通常用于配置场景，业务场景关闭）。 |
| Description | 字段说明。 |

## 字段特性

| 特性 | 说明 |
|------|------|
| 存储内容 | 数据表标识（collection name），如 `orders`、`articles`、`products` |
| 页面组件 | 下拉选择框，选项是数据表列表，显示数据表显示名，保存表标识 |
| 多态关联 | 通常和「记录ID」字段配合使用，两个字段共同确定：哪个表的哪条记录 |
| 联动过滤 | 选择表后，后续的关联记录选择器只显示对应表的记录 |
| 权限 | 可以配置哪些表在可选范围内，敏感表可以排除 |

## 编辑配置

创建后，点击字段右侧的「Edit」可以编辑表选择器字段配置。

| 配置 | 允许编辑 | 说明 |
|------|----------|------|
| Field display name | 是 | 修改字段显示名称。 |
| Field name | 否 | 字段标识创建后不建议修改。 |
| Available collections | 是 | 调整可选数据表范围。 |
| Description | 是 | 补充字段说明。 |

## 删除字段

点击字段右侧的「Delete」可以删除表选择器字段。如果是多态关联的一部分，删除后无法再确定关联记录属于哪个表。

## 多态关联模式

表选择器最常见的用法是实现多态关联（Polymorphic Association），通常需要两个字段：

| 字段 | 字段类型 | 作用 |
|------|----------|------|
| 关联表 | 表选择器（Collection select） | 存储关联哪个数据表，如 `orders` |
| 关联记录ID | 数字/字符串字段 | 存储该表中记录的主键 ID，如 `1001` |

两个字段组合起来表示：关联到 **orders 表的 ID=1001** 这条订单记录。

**常见多态关联场景：**
* **评论系统**：一张评论表，可以评论商品、文章、订单，评论表加 `commentable_type`（表选择器）和 `commentable_id`（记录ID）
* **附件关联**：附件可以上传到文章、商品、用户头像，附件表加 `related_type` 和 `related_id`
* **操作日志**：通用日志表记录任意表的增删改操作，日志表加 `collection_name` 和 `record_id`
* **审批记录**：通用审批可以审批任意业务单据，审批表加 `collection_name` 和 `form_id`

## 页面配置使用

| 场景 | 用途 |
|------|------|
| 通用表单 | 用户选择关联的数据表后，动态加载对应表的记录选择器，选择具体记录。 |
| 详情展示 | 显示关联表的显示名，如"订单"、"文章"，点击可以跳转到对应记录详情。 |
| 通用列表 | 操作日志、评论列表显示"所属模块"（关联表名称），按类型筛选。 |
| 系统配置 | 在低代码配置页面，选择需要关联的数据表。 |

## 注意事项

1. **多态关联的缺点**：多态关联无法在数据库层面建立外键约束，数据一致性需要应用层保证；关联查询也比普通外键关联复杂，不要滥用。
2. **什么时候用多态关联**：当多个表确实需要被同一个通用功能关联，且表数量可能动态增加时使用；如果关联表类型固定且不多，使用多对多关联更规范。
3. **可选范围控制**：业务场景下一定要配置 Available collections 限制可选表，避免用户选择系统表导致错误。
4. **表名稳定性**：数据表重命名会导致历史数据中存储的表名失效，系统表不要随意改名。
