# 几何线（LineString）

> 来源：NocoBase 文档整理
> 整理时间：2026-09-02

## 介绍

在 NocoBase 中，**几何线（LineString）** 属于几何图形字段，用于存储由多个点连成的路径或线条。

几何线字段用于表示路线、轨迹、边界线等线性地理要素，可以在地图上绘制折线。适合配送路线、巡检路线、道路、行政边界线等场景。

## 适用场景

几何线适合这些业务场景：

* 配送路线、巡检路线、行驶轨迹
* 道路、河流、管线、线路
* 行政边界、区域边界线
* 路径规划结果存储

## 创建配置

在数据表的「Configure fields」页面中，点击「Add field」，在几何图形类型中选择「线」可以创建几何线字段。

| 配置 | 说明 |
|------|------|
| Field interface | 字段的界面类型。线对应 lineString，用于在地图上绘制折线。 |
| Field display name | 字段在界面中显示的名称，比如「配送路线」「巡检轨迹」。 |
| Field name | 字段标识名称，用于 API、权限、工作流等内部引用。创建后通常不再修改。 |
| Field type | 字段在数据层的类型。线使用 linestring 空间类型。 |
| SRID | 空间参考标识符，默认 4326（WGS84）。 |
| Map provider | 地图服务商配置。 |
| Description | 字段说明。 |

## 字段特性

| 特性 | 说明 |
|------|------|
| Field type | linestring |
| 数据格式 | GeoJSON LineString 格式，`{ "type": "LineString", "coordinates": [[lng1,lat1], [lng2,lat2], ...] }` |
| 页面组件 | 地图绘制组件，支持点击加点绘制折线、拖拽调整节点 |
| 空间计算 | 支持长度计算、相交判断、包含判断 |
| 展示 | 支持在地图上展示线条，可配置颜色、粗细 |

## 编辑配置

创建后，点击字段右侧的「Edit」可以编辑几何线字段配置。

| 配置 | 允许编辑 | 说明 |
|------|----------|------|
| Field display name | 是 | 修改字段显示名称。 |
| Field name | 否 | 字段标识创建后不建议修改。 |
| Map provider | 是 | 切换地图服务商。 |
| Line style | 是 | 配置线条颜色、粗细、透明度。 |
| Description | 是 | 补充字段说明。 |

## 删除字段

点击字段右侧的「Delete」可以删除几何线字段。删除会丢失所有路线数据。

## 页面配置使用

| 场景 | 用途 |
|------|------|
| 表单区块 | 地图上点击绘制路径，支持添加节点、删除节点、拖拽调整。 |
| 详情区块 | 地图展示绘制的路线，显示线路样式。 |
| 地图区块 | 批量展示多条路线，可点击查看详情。 |
| 计算 | 自动计算路线总长度。 |
