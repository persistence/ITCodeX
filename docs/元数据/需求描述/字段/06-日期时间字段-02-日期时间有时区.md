# 日期时间（带时区）（Datetime with time zone）

> 来源：https://docs.nocobase.com/cn/data-sources/data-modeling/collection-fields/datetime/datetime-tz
> 整理时间：2026-09-02

## 介绍

在 NocoBase 中，**日期时间（带时区）（Datetime with time zone）** 用于保存带时区信息的日期时间值。

这个字段适合跨时区业务，比如全球会议时间、国际业务发生时间、云服务事件时间等。存储时保存时区信息，展示时可以根据用户所在时区自动转换。

如果业务只在单个时区运行，不需要时区转换，选择日期时间（无时区）字段即可。

## 适用场景

日期时间（带时区）适合这些业务场景：

* 全球会议时间、跨时区排期
* 国际订单时间、跨境业务发生时间
* 云服务日志时间、系统事件时间
* 需要根据用户时区自动转换的时间

## 创建配置

在数据表的「Configure fields」页面中，点击「Add field」，选择「日期时间（带时区）」可以创建日期时间（带时区）字段。

| 配置 | 说明 |
|------|------|
| Field interface | 字段的界面类型。日期时间（带时区）对应 datetimeTz，决定页面中如何录入和展示。 |
| Field display name | 字段在界面中显示的名称，比如「全球会议时间」「国际订单时间」「事件时间」。建议使用业务人员能直接理解的名称。 |
| Field name | 字段标识名称，用于 API、关系字段、权限、工作流等内部引用。创建后通常不再修改，只支持字母、数字和下划线，并且必须以字母开头。 |
| Field type | 字段在数据层的类型。日期时间（带时区）通常使用 timestamptz 或带时区的 datetime 类型，具体以数据源支持为准。 |
| Display format | 展示格式，可以配置日期时间格式和时区显示方式。 |
| Default value | 默认值。可以选择当前时间或固定时间。新增记录时，如果用户没有填写，可以自动带出默认值。 |
| Validation rules | 校验规则。可以配置日期范围、是否必填。 |
| Description | 字段说明。适合写字段含义、填写要求、数据来源或维护人。 |

> **注意**：字段名创建后会被页面区块、权限、工作流和 API 引用。创建前先确认命名，避免后续修改带来配置调整成本。

## 字段特性

| 特性 | 说明 |
|------|------|
| 默认 Field interface | datetimeTz。 |
| 默认 Field type | timestampTz。 |
| 可选 Field type | 带时区的 datetime、timestamptz。 |
| 页面组件 | 编辑模式使用日期时间选择器，可以选择时区。 |
| 筛选 | 支持日期范围、早于、晚于、等于、为空、不为空等筛选。 |
| 排序 | 支持按时间排序。 |
| 时区 | 存储时区信息，支持根据用户时区自动转换展示。 |

## 编辑配置

创建后，点击字段右侧的「Edit」可以编辑日期时间（带时区）字段配置。编辑字段主要用于调整字段在 NocoBase 中的展示和使用方式，比如修改显示名称、说明、默认值、校验规则或展示格式。

如果字段来自主数据库中已经同步的表，编辑时通常是在做字段映射——把数据库字段映射为 NocoBase 的 Field type 和 Field interface。

| 配置 | 允许编辑 | 说明 |
|------|----------|------|
| Field display name | 是 | 修改字段在界面中的显示名称，不改变字段标识名称。 |
| Field name | 否 | 字段标识名称创建后通常不能在编辑表单中修改。 |
| Field interface | 条件支持 | 主数据库字段或同步字段在字段映射时可以调整。调整后会影响页面输入、展示和校验方式。 |
| Field type | 条件支持 | 主数据库字段或同步字段在字段映射时可以调整。调整前需要确认已有数据能否按新类型使用。 |
| Display format | 是 | 调整日期时间展示格式和时区展示方式。 |
| Default value | 是 | 调整新增记录时的默认值。 |
| Validation rules | 是 | 调整字段校验规则。 |
| Description | 是 | 补充字段含义、填写要求、数据来源或维护人。 |

> **注意**：切换 Field type 或 Field interface 不等于简单改一个显示名称。它会影响字段的存储方式、输入组件、校验规则、筛选条件和工作流变量使用方式。已有数据较多时，先确认数据格式是否匹配。

## 删除字段

点击字段右侧的「Delete」可以删除日期时间（带时区）字段。主数据库中还可以勾选多个字段后批量删除。

删除主数据库中新建的日期时间（带时区）字段时，通常会同时删除数据库中的真实列及该列已有数据。删除从数据库同步或外部数据源映射出的字段时，影响范围取决于对应数据源和字段来源。

> ⚠️ **警告**：删除字段可能影响页面区块、表单、筛选、权限、工作流、API、导入导出和已有数据。删除前先确认字段是否仍被业务配置引用。

## 页面配置使用

日期时间（带时区）适合跨时区业务场景。

| 场景 | 用途 |
|------|------|
| 表单区块 | 选择带时区的日期时间。 |
| 表格区块 | 按用户时区展示时间并支持排序、筛选。 |
| 日历区块 | 跨时区事件展示。 |
| 工作流和权限 | 按统一时间标准触发流程或判断条件。 |
