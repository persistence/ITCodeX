# 公式（Formula）

> 来源：NocoBase 文档整理
> 整理时间：2026-09-02

## 介绍

在 NocoBase 中，**公式（Formula）** 属于高级类型字段，用于通过表达式自动计算字段值。

公式字段是虚拟字段，不会存储在数据库中，每次读取记录时根据配置的公式表达式实时计算结果。可以引用当前记录的其他字段、使用数学运算、字符串函数、日期函数、逻辑判断等。

公式字段的值自动计算，用户不能手动编辑，适合金额计算、成绩统计、年龄计算、状态自动判断等场景。

## 适用场景

公式适合这些业务场景：

* 金额计算：订单总价 = 单价 × 数量 × 折扣，税额 = 金额 × 税率
* 数值统计：总分 = 分项分数之和，平均分 = 总分 / 科目数
* 日期计算：年龄 = 当前年份 - 出生年份，到期天数 = 到期日期 - 当前日期
* 字符串拼接：全名 = 姓 + 名，地址 = 省 + 市 + 区 + 详细地址
* 条件判断：状态 = 如果(库存=0, "缺货", "有货")，等级 = 根据分数判断优良中差

## 创建配置

在数据表的「Configure fields」页面中，点击「Add field」，在高级类型中选择「公式」可以创建公式字段。

| 配置 | 说明 |
|------|------|
| Field interface | 字段的界面类型。公式对应 formula，结果只读。 |
| Field display name | 字段在界面中显示的名称，比如「订单总价」「年龄」「状态」。建议名称就是计算结果的业务含义。 |
| Field name | 字段标识名称，用于 API、权限、工作流等内部引用。创建后通常不再修改。 |
| Result data type | 公式计算结果的数据类型，可选数字、字符串、布尔值、日期。决定结果如何展示和使用。 |
| Formula expression | 公式表达式，支持引用其他字段、使用运算符和内置函数。 |
| Description | 字段说明。适合说明计算公式。 |

## 支持的表达式

公式支持常见的运算和函数：

| 类别 | 支持内容 |
|------|----------|
| 数学运算 | 加减乘除 `+ - * /`，取余 `%`，幂运算，括号优先级 |
| 比较运算 | 等于 `==`，不等于 `!=`，大于 `>`，小于 `<`，大于等于 `>=`，小于等于 `<=` |
| 逻辑运算 | 与 `&&`，或 `||`，非 `!`，三元条件 `condition ? a : b` |
| 数学函数 | `SUM()`, `AVG()`, `ROUND()`, `CEIL()`, `FLOOR()`, `ABS()`, `MAX()`, `MIN()`, `SQRT()` |
| 字符串函数 | `CONCAT()`, `SUBSTRING()`, `LENGTH()`, `UPPER()`, `LOWER()`, `TRIM()`, `REPLACE()` |
| 日期函数 | `NOW()`, `DATEADD()`, `DATEDIFF()`, `YEAR()`, `MONTH()`, `DAY()`, `HOUR()` |
| 引用字段 | 使用 `{字段名}` 引用当前记录其他字段值，如 `{price} * {quantity}` |
| 关系字段引用 | 支持引用关系表字段，如 `{customer.level}` 引用关联客户的等级 |

## 字段特性

| 特性 | 说明 |
|------|------|
| 存储方式 | 虚拟字段，计算结果不存储到数据库，每次读取实时计算 |
| 可编辑性 | 用户不能手动编辑公式字段值，结果由公式自动计算 |
| 页面组件 | 只读展示，结果类型决定展示格式（数字保留小数、日期格式化等） |
| 筛选 | 部分情况下支持按公式结果筛选，取决于公式复杂度 |
| 排序 | 简单公式支持排序，复杂聚合公式不支持 |
| 性能 | 复杂公式、引用大量关系字段会影响查询性能，注意优化 |

## 编辑配置

创建后，点击字段右侧的「Edit」可以编辑公式字段配置。

| 配置 | 允许编辑 | 说明 |
|------|----------|------|
| Field display name | 是 | 修改字段显示名称。 |
| Field name | 否 | 字段标识创建后不建议修改。 |
| Formula expression | 是 | 修改公式表达式，修改后所有记录结果会立即更新（因为是实时计算）。 |
| Result data type | 是 | 修改结果类型，注意和公式返回值类型匹配，避免展示错误。 |
| Description | 是 | 补充公式说明。 |

> **注意**：修改公式后不需要数据迁移，所有记录下次读取时自动使用新公式计算。如果公式引用了被删除的字段，公式会出错。

## 删除字段

点击字段右侧的「Delete」可以删除公式字段。删除不会影响其他字段数据，因为公式不存储数据。

> 提示：公式字段是虚拟的，删除不会丢失任何业务数据，可以随时删除重建。

## 页面配置使用

公式字段只读展示，不能编辑。

| 场景 | 用途 |
|------|------|
| 表格/详情区块 | 只读展示计算结果，和普通字段一样显示。 |
| 表单区块 | 新建/编辑表单中可以展示公式结果（实时计算预览），但不能编辑。 |
| 工作流 | 工作流节点可以读取公式字段结果用于判断或赋值。 |
| 权限 | 可以控制公式字段的查看权限，和普通字段一样。 |
| 导出 | 导出数据时会包含公式计算结果。 |

## 公式示例

| 业务场景 | 公式示例 |
|----------|----------|
| 订单总价 | `{unit_price} * {quantity} * (1 - {discount})` |
| 订单税额 | `ROUND({total_amount} * 0.06, 2)` |
| 是否缺货 | `{stock} <= 0 ? "缺货" : "有货"` |
| 年龄计算 | `YEAR(NOW()) - YEAR({birthday})` |
| 订单状态 | `{paid_at} ? "已支付" : ({created_at} < DATEADD(NOW(), -7, "DAY") ? "已过期" : "待支付")` |
| 客户等级 | `{total_order_amount} >= 10000 ? "VIP" : ({total_order_amount} >= 1000 ? "会员" : "普通")` |
| 完整地址 | `CONCAT({province}, {city}, {district}, {address})` |
| 成绩等级 | `{score} >= 90 ? "优秀" : ({score} >= 80 ? "良好" : ({score} >= 60 ? "及格" : "不及格"))` |

## 注意事项

1. **避免循环引用**：公式A引用公式B，公式B又引用公式A，会导致循环计算错误。
2. **性能考虑**：列表查询时如果每条记录都需要复杂计算（特别是引用多条关系数据），会影响性能。对于统计类复杂计算，建议在工作流中计算后存储到普通字段。
3. **空值处理**：公式中引用的字段如果为空值（NULL），计算结果可能为空，需要使用 `IFNULL()` 等函数处理默认值。
4. **结果类型匹配**：确保公式返回值类型和配置的结果类型一致，比如数字字段不要返回字符串。
