# 附件（关联 / Attachment）

> 来源：NocoBase 文档整理
> 整理时间：2026-09-02

## 介绍

在 NocoBase 中，**附件（关联）** 属于多媒体字段类型，用于上传文件并通过关联关系关联到文件表。

附件字段关联到文件表（File Collection），支持上传图片、文档、音视频等各种文件类型。上传的文件会存储到配置的存储引擎（本地存储、S3、OSS、COS 等），文件元数据存储在文件表中，当前记录只保存关联关系。

这是最常用的附件字段类型，适合需要本地上传文件的场景。

## 适用场景

附件（关联）适合这些业务场景：

* 合同附件、发票扫描件、报销凭证
* 产品图片、文章配图、用户头像
* 工单附件、项目文档、设计稿
* 文档、音视频、压缩包等任意文件上传

## 创建配置

在数据表的「Configure fields」页面中，点击「Add field」，在多媒体类型中选择「附件」可以创建附件字段。

| 配置 | 说明 |
|------|------|
| Field interface | 字段的界面类型。附件对应 attachment，决定页面中如何上传和展示文件。 |
| Field display name | 字段在界面中显示的名称，比如「合同附件」「产品图片」「头像」。建议使用业务人员能直接理解的名称。 |
| Field name | 字段标识名称，用于 API、权限、工作流等内部引用。创建后通常不再修改。 |
| Target collection | 目标表，默认是系统文件表 `files`。 |
| Storage | 存储引擎，选择文件存储位置，比如本地存储、S3、阿里云 OSS、腾讯云 COS 等。 |
| Multiple | 是否允许多个文件上传。单文件上传（如头像）关闭此项，多附件（如合同附件）开启。 |
| Accepted file types | 允许上传的文件类型，比如 `image/*` 只允许图片，`.pdf,.doc,.docx` 只允许文档。 |
| Max file size | 单个文件最大大小限制。 |
| Description | 字段说明。适合写上传要求、支持格式等。 |

> **注意**：使用附件字段前需要先在文件管理器中配置好存储引擎。

## 字段特性

| 特性 | 说明 |
|------|------|
| Field type | 关系类型，单附件是 hasOne，多附件是 hasMany |
| 关联表 | 关联到系统文件表或自定义文件表 |
| 存储 | 文件存储在配置的存储引擎，数据库只存文件元数据和关联关系 |
| 页面组件 | 编辑模式使用上传组件，支持拖拽上传、预览、删除 |
| 图片展示 | 图片类型支持缩略图、预览大图、裁剪 |
| 文件展示 | 非图片文件显示文件名、大小、下载链接 |
| 多文件 | 支持多文件上传，以列表或卡片形式展示 |

## 文件元数据

文件表中保存的文件元数据通常包括：

| 字段 | 说明 |
|------|------|
| filename | 原始文件名 |
| path | 文件存储路径 |
| URL | 文件访问 URL |
| size | 文件大小（字节） |
| mimetype | 文件 MIME 类型 |
| extname | 文件扩展名 |
| title | 文件标题（可编辑） |
| description | 文件说明（可编辑） |
| storage | 使用的存储引擎标识 |
| createdBy | 上传人 |
| createdAt | 上传时间 |

## 编辑配置

创建后，点击字段右侧的「Edit」可以编辑附件字段配置。

| 配置 | 允许编辑 | 说明 |
|------|----------|------|
| Field display name | 是 | 修改字段显示名称。 |
| Field name | 否 | 字段标识创建后不建议修改。 |
| Multiple | 谨慎修改 | 从单文件改为多文件可以，从多文件改为单文件需要先清理历史数据。 |
| Accepted file types | 是 | 调整允许上传的文件类型。 |
| Max file size | 是 | 调整文件大小限制。 |
| Storage | 谨慎修改 | 修改存储引擎不会迁移历史文件，只影响新上传文件。 |
| Description | 是 | 补充上传说明。 |

> **注意**：修改存储引擎不会自动迁移已经上传的文件，历史文件访问路径可能失效。

## 删除字段

点击字段右侧的「Delete」可以删除附件字段。删除附件字段只会删除当前记录和文件的关联关系，不会删除文件表中的文件记录和存储中的实际文件。

> ⚠️ **警告**：如果需要清理 orphan 文件（没有被任何记录引用的文件），需要单独执行文件清理操作。删除关联字段不会自动删除文件，避免误删其他记录也在引用的文件。

## 页面配置使用

附件字段在表单、详情、表格中都有丰富的展示方式。

| 场景 | 用途 |
|------|------|
| 表单区块 | 拖拽上传文件，支持预览、删除、重新上传。 |
| 详情区块 | 展示文件列表，图片显示缩略图，支持预览和下载。 |
| 表格区块 | 单图片显示缩略图，多文件显示文件数量或第一个文件。 |
| 头像场景 | 单图片上传，支持圆形裁剪展示。 |
| 画廊展示 | 多图片支持画廊模式预览、左右切换。 |
