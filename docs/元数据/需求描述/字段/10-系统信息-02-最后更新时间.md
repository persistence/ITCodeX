# 最后更新时间（Last updated at）

> 来源：NocoBase 文档整理
> 整理时间：2026-09-02

## 介绍

在 NocoBase 中，**最后更新时间（Last updated at / Updated at）** 属于系统信息字段，由系统自动维护，记录每条记录最后一次修改的时间。

最后更新时间和创建时间一样，是系统字段，创建普通表时默认自动添加，用户不能手动修改。每次修改记录（任何字段更新）时，系统自动更新这个时间为当前时间。常用于看最近修改的数据、判断数据是否最新、增量同步。

## 适用场景

最后更新时间默认添加到所有普通表，主要用于：

* 记录数据最后一次被修改的时间
* 按更新时间排序，查看最近修改过的记录（优先处理刚更新的）
* 筛选最近N天有更新的记录
* 数据增量同步：外部系统拉取数据时只拉取更新时间大于上次同步时间的数据
* 判断数据版本是否变化，做缓存失效
* 审计追溯，知道数据最后改动时间

## 创建配置

创建普通数据表时，系统默认会自动添加最后更新时间字段，不需要手动创建。如果需要手动添加，在系统信息中选择「最后更新时间」。

| 配置 | 说明 |
|------|------|
| Field interface | 字段的界面类型。更新时间对应 updatedAt，只读展示。 |
| Field display name | 字段在界面中显示的名称，默认是「最后更新时间」。 |
| Field name | 字段标识名称，固定为 `updatedAt`，不建议修改。 |
| Field type | 字段在数据层的类型。日期时间类型，datetime。 |
| Timezone | 时区处理配置。 |
| Auto fill | 自动填充，默认开启，记录创建和每次更新时自动设置为当前时间。 |

## 字段特性

| 特性 | 说明 |
|------|------|
| 自动添加 | 创建普通表时默认自动添加 |
| 创建时设置 | 新建记录时，`updatedAt` 和 `createdAt` 初始值相同，都是创建时间 |
| 更新时自动更新 | 记录任何字段修改保存后，自动更新 `updatedAt = NOW()`，即使字段值实际没变化也会更新（取决于更新实现） |
| 可编辑性 | 用户不能手动修改更新时间，系统自动维护 |
| 页面组件 | 只读展示日期时间，支持格式化 |
| 排序 | 常用于按"最近更新"排序，是工作列表常用排序方式 |
| 筛选 | 支持日期范围筛选，常用于"最近7天更新"等筛选条件 |
| 索引 | 建议加索引，增量同步和排序经常用到 |

## 编辑配置

最后更新时间作为系统字段，一般不允许修改配置。

| 配置 | 允许编辑 | 说明 |
|------|----------|------|
| Field display name | 是 | 可以修改显示名称，比如「修改时间」「更新时间」。 |
| Field name | 否 | 系统字段标识 `updatedAt` 不建议修改。 |
| Date format | 是 | 调整页面显示的日期时间格式。 |
| Description | 是 | 添加字段说明。 |

## 删除字段

和创建时间一样，**强烈不建议删除**最后更新时间字段。删除后无法知道数据最后修改时间，影响增量同步、最近修改排序、审计追溯等功能。

## 页面配置使用

| 场景 | 用途 |
|------|------|
| 表格区块 | 显示最后更新时间列，默认工作列表常按更新时间倒序，最近修改的排在前面，方便处理。 |
| 详情区块 | 显示在元信息区域，和创建时间一起展示，如"创建于 2024-05-01，最后更新于 2024-05-12"。 |
| 表单区块 | 编辑表单只读展示，用户不能修改。 |
| 列表筛选 | 常用筛选条件："最近7天有更新"、"最近一个月修改过"。 |
| 增量同步 | 外部系统同步数据时，核心字段就是 `updatedAt`，每次只拉取 `updatedAt > lastSyncTime` 的数据，比全量同步效率高很多。 |
| 缓存 | 判断记录是否有更新，缓存的更新时间和当前不一致则刷新缓存。 |
| 工作流 | 可以根据更新时间触发，比如"记录修改后N天未跟进"自动提醒。 |

## 默认行为

* **新建记录**：`updatedAt` 初始值等于 `createdAt`，即创建时间。
* **更新记录**：任何字段修改，保存时自动将 `updatedAt` 更新为当前时间。**注意**：如果更新操作字段值没有实际变化（和原值相同），某些实现可能不会更新 `updatedAt`。
* **软删除/恢复**：软删除通常会更新 `updatedAt`，恢复也会更新。
* **数据导入**：导入时如果指定了 `updatedAt`，保留指定值；否则使用导入时间。增量导入建议带上原始更新时间。
* **批量更新**：批量修改操作也会更新每条符合条件记录的 `updatedAt`。

> **注意**：关系变化（比如关联、取消关联）通常也会更新主记录的 `updatedAt`，因为关系属于记录的一部分。

## created_at vs updated_at 对比

| 场景 | createdAt | updatedAt |
|------|-----------|-----------|
| 新建记录 | 设置为当前时间 | 和 createdAt 相同 |
| 修改记录 | 不变 | 更新为当前时间 |
| 删除记录 | 不变 | 更新为当前时间 |
| 恢复记录 | 不变 | 更新为当前时间 |
| 是否允许修改 | 不允许 | 不允许 |
| 用途 | 追溯数据什么时候进入系统 | 追溯数据最后什么时候改动 |
| 排序 | 按录入时间排序 | 按最近活跃度排序 |
