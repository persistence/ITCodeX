# 附件（URL）

> 来源：NocoBase 文档整理
> 整理时间：2026-09-02

## 介绍

在 NocoBase 中，**附件（URL）** 属于多媒体字段类型，用于关联已经存在于外部 URL 的文件，不需要上传到本地存储。

附件（URL）字段同样关联到文件表，但不会上传文件到 NocoBase 配置的存储引擎，而是直接保存外部文件的 URL 地址。适合文件已经存储在外部系统、CDN 或对象存储中，只需要在 NocoBase 中引用展示的场景。

和附件（关联）字段的区别是：不做本地上传，直接引用外部链接。

## 适用场景

附件（URL）适合这些业务场景：

* 文件已经存储在外部 CDN 或对象存储
* 引用其他系统的文件链接
* 不需要通过 NocoBase 上传，只需要展示和下载
* 图片外链、文档外链、视频链接

## 创建配置

在数据表的「Configure fields」页面中，点击「Add field」，在多媒体类型中选择「附件（URL）」可以创建该字段。

| 配置 | 说明 |
|------|------|
| Field interface | 字段的界面类型。附件(URL) 对应 attachmentUrl，页面中通过URL添加文件。 |
| Field display name | 字段在界面中显示的名称，比如「外部图片」「文件链接」。 |
| Field name | 字段标识名称，用于 API、权限、工作流等内部引用。创建后通常不再修改。 |
| Target collection | 目标表，默认是系统文件表 `files`。 |
| Multiple | 是否允许多个文件链接。单文件关闭，多文件开启。 |
| Accepted file types | 允许的文件类型，比如 `image/*` 只允许图片链接。 |
| Description | 字段说明。适合填写链接要求说明。 |

## 字段特性

| 特性 | 说明 |
|------|------|
| Field type | 关系类型，单附件是 hasOne，多附件是 hasMany |
| 关联表 | 关联到系统文件表 |
| 存储 | 不存储文件本身，只存储外部 URL 和元数据 |
| 上传方式 | 不需要拖拽上传，直接输入或粘贴外部 URL |
| 页面组件 | URL 输入框，支持预览、验证链接有效性 |
| 展示方式 | 和普通附件一样，支持预览、下载、缩略图展示 |

## 编辑配置

创建后，点击字段右侧的「Edit」可以编辑附件（URL）字段配置。

| 配置 | 允许编辑 | 说明 |
|------|----------|------|
| Field display name | 是 | 修改字段显示名称。 |
| Field name | 否 | 字段标识创建后不建议修改。 |
| Multiple | 谨慎修改 | 单文件改多文件可以，反向需要清理数据。 |
| Accepted file types | 是 | 调整允许的文件类型。 |
| Description | 是 | 补充说明。 |

## 删除字段

点击字段右侧的「Delete」可以删除附件（URL）字段。删除只会移除关联关系，不会删除外部文件。

> ⚠️ **注意**：外部文件的可用性由外部系统保证，NocoBase 不负责外部文件的存储和生命周期管理。

## 页面配置使用

| 场景 | 用途 |
|------|------|
| 表单区块 | 输入外部文件 URL 添加附件。 |
| 详情区块 | 和普通附件一样展示，支持预览、下载。 |
| 表格区块 | 显示缩略图或文件名链接。 |
| 外部资源引用 | 引用CDN资源、其他系统的文件。 |

## 与附件（关联）的区别

| 对比项 | 附件（关联） | 附件（URL） |
|--------|--------------|-------------|
| 文件存储 | 上传到NocoBase配置的存储引擎 | 文件在外部，只保存URL |
| 上传方式 | 拖拽/选择本地上传 | 输入/粘贴外部URL |
| 文件管理 | NocoBase管理文件元数据和生命周期 | NocoBase只引用，不管理文件本身 |
| 适用场景 | 需要本地上传新文件 | 文件已存在外部系统 |
