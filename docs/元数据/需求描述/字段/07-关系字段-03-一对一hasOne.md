# 一对一（hasOne）

> 来源：NocoBase 文档整理
> 整理时间：2026-09-02

## 介绍

在 NocoBase 中，**一对一（hasOne）** 关系表示当前表的一条记录只能关联目标表的一条记录，目标表的一条记录也只能关联当前表的一条记录。

一对一关系适合扩展信息拆分场景。例如：用户表和用户详情表，一个用户对应一份详情信息，把不常用的大字段拆分到详情表可以提升主表查询性能。一对一关系在目标表创建外键。

如果一对一关系不强烈，或者扩展字段不多，直接把字段放在主表更简单。

## 适用场景

一对一适合这些业务场景：

* 用户与用户详情、员工与员工档案
* 订单与发票信息、合同与合同补充条款
* 大字段拆分：把富文本、JSON 等不常用大字段拆分到扩展表
* 需要权限隔离的信息拆分，比如薪资信息单独存一张表

## 创建配置

在数据表的「Configure fields」页面中，点击「Add field」，选择「一对一」可以创建一对一关系字段。

| 配置 | 说明 |
|------|------|
| Field interface | 字段的界面类型。一对一通常对应 recordPicker 或嵌套表单组件，决定页面中如何展示关联记录。 |
| Field display name | 字段在界面中显示的名称，比如「用户详情」「发票信息」「档案信息」。建议使用业务人员能直接理解的名称。 |
| Field name | 字段标识名称，用于 API、权限、工作流等内部引用。创建后通常不再修改。 |
| Target collection | 目标数据表，即扩展信息表。 |
| Foreign key | 外键字段名，目标表中存储当前记录 ID 的字段，比如 `userId`、`orderId`。 |
| Source key | 当前表的键字段，通常是主键 ID。 |
| Allow creating new records | 是否允许在当前页面直接新建关联的扩展记录。 |
| Description | 字段说明。适合写字段含义或维护规则。 |

> **注意**：一对一关系需要保证外键唯一，否则会退化成一对多关系。

## 字段特性

| 特性 | 说明 |
|------|------|
| Field type | hasOne（关系类型，不创建新的数据列）。 |
| 数据库列 | 在目标表创建外键列，通常会加唯一约束。 |
| 页面组件 | 编辑模式使用数据选择器或嵌套表单。 |
| 筛选 | 支持按关联记录筛选。 |
| 关系方向 | 反向关系是 belongsTo（多对一），因为外键在目标表。 |
| 唯一性 | 一条主记录只能对应一条扩展记录。 |

## 关系示例

典型的一对一关系配置示例：

* **用户 → 用户详情**：用户表（users）通过 `profile` 关系关联用户详情表（user_profiles），详情表通过 `userId` 外键（唯一）关联用户。
* **订单 → 发票**：订单表（orders）通过 `invoice` 关系关联发票表（invoices），发票表通过 `orderId` 外键（唯一）关联订单。
* **员工 → 薪资信息**：员工表（employees）通过 `salary` 关系关联薪资表（salaries），薪资表通过 `employeeId` 外键（唯一）关联员工。

## 编辑配置

创建后，点击字段右侧的「Edit」可以编辑一对一关系字段配置。

| 配置 | 允许编辑 | 说明 |
|------|----------|------|
| Field display name | 是 | 修改字段在界面中的显示名称。 |
| Field name | 否 | 关系字段标识创建后通常不建议修改。 |
| Target collection | 谨慎修改 | 修改目标表会影响关联。 |
| Foreign key | 否 | 外键创建后不建议修改。 |
| Display mode | 是 | 调整是弹出编辑还是页面内嵌套展示。 |
| Allow operations | 是 | 调整是否允许新建、编辑关联记录。 |
| Description | 是 | 补充字段说明。 |

> **注意**：如果外键没有唯一约束，系统可能按一对多处理，导致查询只返回第一条关联记录。

## 删除字段

点击字段右侧的「Delete」可以删除一对一关系字段。

> ⚠️ **警告**：删除关系字段会影响页面嵌套表单、详情展示和关联查询。如果目标表的外键列不再使用，需要单独清理。

## 页面配置使用

一对一关系适合在表单和详情中展示扩展信息。

| 场景 | 用途 |
|------|------|
| 表单区块 | 弹出层或页面内嵌套编辑扩展信息。 |
| 详情区块 | 直接展示关联的扩展信息字段。 |
| 关系表字段 | 在表单中只读展示扩展表字段。 |
| 性能优化 | 拆分大字段，主列表查询不加载扩展表内容。 |
