# 一对多（hasMany / 子表格）

> 来源：NocoBase 文档整理
> 整理时间：2026-09-02

## 介绍

在 NocoBase 中，**一对多（hasMany）** 关系表示当前表的一条记录可以关联目标表的多条记录。

一对多关系通常是多对一关系的反向关系，不会在当前表创建额外数据库列，而是通过目标表的外键进行关联。例如：一个客户可以有多个订单，客户表的 `orders` 关系通过订单表的 `customerId` 外键查询所有关联订单。在界面上通常使用子表格、子列表等组件展示多条关联记录。

如果是从无到有新建关系，通常是在从表创建多对一关系，主表自动生成一对多反向关系。

## 适用场景

一对多适合这些业务场景：

* 客户有多个订单、部门有多个员工
* 文章有多条评论、订单有多个订单明细
* 项目有多个任务、客户有多个联系人
* 一条主记录下管理多条子记录的场景

## 创建配置

在数据表的「Configure fields」页面中，点击「Add field」，选择「一对多」或「子表格」可以创建一对多关系字段。如果已经创建了反向多对一关系，通常会自动生成一对多关系。

| 配置 | 说明 |
|------|------|
| Field interface | 字段的界面类型。一对多通常对应 subTable（子表格）、subList 等组件，决定页面中如何展示和编辑多条关联记录。 |
| Field display name | 字段在界面中显示的名称，比如「订单列表」「评论列表」「订单明细」。建议使用业务人员能直接理解的名称。 |
| Field name | 字段标识名称，用于 API、权限、工作流等内部引用。创建后通常不再修改，只支持字母、数字和下划线，并且必须以字母开头。 |
| Target collection | 目标数据表，即当前记录关联的子记录表，比如「订单表」「评论表」。 |
| Foreign key | 外键字段名，目标表中存储当前记录 ID 的字段，比如 `customerId`、`articleId`。 |
| Source key | 当前表的键字段，通常是当前表的主键 ID。 |
| Allow selecting existing records | 是否允许从已有记录中选择关联，默认开启。 |
| Allow creating new records | 是否允许在子表格中直接新建子记录。 |
| Allow unlinking existing records | 是否允许解除已有数据的关联。 |
| Description | 字段说明。适合写字段含义、维护规则或注意事项。 |

> **注意**：一对多关系通常与多对一关系成对出现。在从表创建多对一关系是更规范的做法，主表的一对多关系会自动生成。

## 字段特性

| 特性 | 说明 |
|------|------|
| Field type | hasMany（关系类型，不创建新的数据列）。 |
| 数据库列 | 不在当前表创建列，使用目标表的外键列关联。 |
| 页面组件 | 编辑模式使用子表格（行内编辑）、子列表等组件。 |
| 筛选 | 支持按子记录条件筛选主记录。 |
| 排序 | 支持对子记录排序。 |
| 关系方向 | 反向关系是 belongsTo（多对一）。 |

## 关系示例

典型的一对多关系配置示例：

* **客户 → 订单**：客户表（customers）通过 `orders` 关系关联订单表（orders），订单表通过 `customerId` 外键存储客户 ID。
* **文章 → 评论**：文章表（articles）通过 `comments` 关系关联评论表（comments），评论表通过 `articleId` 外键存储文章 ID。
* **部门 → 员工**：部门表（departments）通过 `users` 关系关联用户表（users），用户表通过 `departmentId` 外键存储部门 ID。

## 编辑配置

创建后，点击字段右侧的「Edit」可以编辑一对多关系字段配置。编辑关系字段主要用于调整界面展示、编辑权限和组件选择。

| 配置 | 允许编辑 | 说明 |
|------|----------|------|
| Field display name | 是 | 修改字段在界面中的显示名称。 |
| Field name | 否 | 关系字段标识创建后通常不建议修改。 |
| Target collection | 谨慎修改 | 修改目标表会影响所有关联数据。 |
| Foreign key | 否 | 外键创建后不建议修改。 |
| Field component | 是 | 可以切换子表格、子列表等组件。 |
| Allow operations | 是 | 调整是否允许新建、选择、删除、解除关联等操作。 |
| Display fields | 是 | 配置子表格/列表中显示哪些字段。 |
| Description | 是 | 补充字段说明。 |

> **注意**：子表格中可以配置显示哪些字段、哪些字段可编辑。大字段（富文本、JSON、多行文本）通常通过悬浮弹窗编辑。

## 删除字段

点击字段右侧的「Delete」可以删除一对多关系字段。如果这是反向自动生成的关系，删除后通常不会删除目标表的外键，只会删除当前表的关系配置。

> ⚠️ **警告**：删除关系字段会影响：
> 1. 页面中已经配置的子表格、子列表
> 2. 详情页中嵌套展示的子记录
> 3. 工作流中对多条子记录的处理
> 4. API 查询中的关联查询
> 
> 删除前务必确认页面配置依赖。

## 页面配置使用

一对多关系字段适合在详情页和表单中管理子记录。

| 场景 | 用途 |
|------|------|
| 详情区块 | 使用子表格或子列表展示所有关联子记录。 |
| 编辑表单 | 在主记录编辑页面行内新增/编辑子记录，例如编辑订单时同时编辑订单明细。 |
| 子表格组件 | 支持批量新建目标表数据，支持从已有数据选择关联，不同字段类型显示对应编辑组件。 |
| 级联操作 | 配合数据库级联或工作流，删除主记录时处理子记录。 |
| 统计 | 在主记录页面统计子记录数量、金额汇总等。 |

## 子表格特性

一对多关系最常用的组件是子表格（行内编辑），它有这些特点：

* 支持批量新建子记录
* 支持从已有数据选择关联
* 不同字段类型显示对应编辑组件
* 大字段（富文本、JSON、多行文本）通过悬浮弹窗编辑
* 子表格中的关系字段默认使用下拉选择器或数据选择器

## 相关链接

* 多对一（belongsTo）— 反向关系，从子记录关联到主记录
* 多对多（belongsToMany）— 双方都可以关联多条记录
* 子表格(行内编辑) — 页面区块中的使用方式
