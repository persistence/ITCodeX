# 排序（Sort）

> 来源：NocoBase 文档整理
> 整理时间：2026-09-02

## 介绍

在 NocoBase 中，**排序（Sort）** 属于高级类型字段，用于支持拖拽调整记录的显示顺序。

排序字段会存储一个数字序号，在表格区块、列表区块支持拖拽行排序，自动更新序号值。常用于菜单排序、轮播图排序、商品排序、分类排序等需要自定义顺序的场景。

当需要让用户可以拖拽调整记录顺序时使用排序字段。

## 适用场景

排序适合这些业务场景：

* 导航菜单、分类的显示顺序
* 轮播图、推荐位、首页区块排序
* 商品列表、文章列表的自定义排序
* 选项、字典项的排序
* 拖拽调整优先级或顺序的所有场景

## 创建配置

在数据表的「Configure fields」页面中，点击「Add field」，在高级类型中选择「排序」可以创建排序字段。

| 配置 | 说明 |
|------|------|
| Field interface | 字段的界面类型。排序对应 sort，提供拖拽排序交互。 |
| Field display name | 字段在界面中显示的名称，通常叫「排序」「显示顺序」「排序号」。 |
| Field name | 字段标识名称，用于 API、权限、工作流等内部引用。创建后通常不再修改。 |
| Field type | 字段在数据层的类型。排序字段为数字类型，通常是 integer。 |
| Default value | 默认排序值，新创建记录默认序号，通常默认放在最后。 |
| New records position | 新记录插入位置，默认放到最后，也可以配置插到最前面。 |
| Scope | 排序范围，支持按父级或分组字段排序，比如在同一个父分类下独立排序。 |
| Description | 字段说明。 |

## 字段特性

| 特性 | 说明 |
|------|------|
| Field type | integer 数字类型 |
| 页面交互 | 表格区块支持拖拽行调整顺序，自动更新序号 |
| 排序规则 | 默认按排序字段升序排列，数字小的在前 |
| 自动重排 | 拖拽插入时自动调整相邻记录的序号，保证序号连续（或间隔足够） |
| 范围排序 | 支持分组排序，每个分组内部独立排序，比如子菜单在父菜单下排序 |
| 默认行为 | 新记录默认追加到最后，序号取当前最大序号 + 步长 |

## 编辑配置

创建后，点击字段右侧的「Edit」可以编辑排序字段配置。

| 配置 | 允许编辑 | 说明 |
|------|----------|------|
| Field display name | 是 | 修改字段显示名称。 |
| Field name | 否 | 字段标识创建后不建议修改。 |
| Scope | 谨慎修改 | 修改排序分组范围后，已有排序可能需要重新调整。 |
| New records position | 是 | 调整新记录默认插入位置。 |
| Description | 是 | 补充字段说明。 |

> **注意**：排序字段的具体数值对用户通常不可见，用户只需要通过拖拽调整顺序，不需要手动输入序号。

## 删除字段

点击字段右侧的「Delete」可以删除排序字段。删除后无法再拖拽排序，列表恢复按创建时间或其他字段排序。

## 页面配置使用

排序字段主要配合表格区块使用，实现拖拽排序。

| 场景 | 用途 |
|------|------|
| 表格区块 | 开启拖拽排序后，行首显示拖拽手柄，拖拽调整行顺序，自动保存排序。 |
| 列表区块 | 支持拖拽调整列表项顺序。 |
| 树形表格 | 支持同一父节点下的子节点拖拽排序。 |
| 查询 | 默认列表查询会按排序字段升序排列。 |

## 实现原理

排序字段通常使用「间隔排序」算法：
1. 初始创建时序号按步长递增（如 10, 20, 30...），留出间隔方便插入
2. 拖拽插入到两条记录之间时，新序号取前后两条记录序号的中间值
3. 当间隔不足时，会对整个列表（或分组）重新编号
4. 这样避免每次拖拽都更新大量记录序号，只需要更新被拖拽记录的值

## 注意事项

* 一个数据表通常只需要一个排序字段，如果需要多个排序维度（如推荐排序、价格排序），可以建多个排序字段配合不同视图使用。
* 如果开启了 Scope 分组排序，拖拽只能在同一分组内进行，跨分组拖拽需要走移动功能。
* 不要让用户手动编辑排序数字，通过拖拽交互自动维护，避免序号混乱。
