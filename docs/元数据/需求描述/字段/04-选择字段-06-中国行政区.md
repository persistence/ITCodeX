# 中国行政区（China region）

> 来源：NocoBase 文档整理
> 整理时间：2026-09-02

## 介绍

在 NocoBase 中，**中国行政区（China region）** 属于选择类型字段，用于选择中国省、市、区/县三级行政区划。

中国行政区字段内置了完整的中国行政区划数据，支持级联选择省、市、区，不需要用户自己维护选项列表。适合收货地址、归属区域、门店区域等需要选择国内行政区划的场景。

如果只需要选择省份或城市，也可以配置选择层级。

## 适用场景

中国行政区适合这些业务场景：

* 用户收货地址、联系地址中的省市区选择
* 门店归属区域、销售区域划分
* 客户所在地区、服务覆盖区域
* 统计报表按地区维度分析

## 创建配置

在数据表的「Configure fields」页面中，点击「Add field」，在选择类型中选择「中国行政区」可以创建中国行政区字段。

| 配置 | 说明 |
|------|------|
| Field interface | 字段的界面类型。中国行政区对应 chinaRegion，决定页面中如何选择。 |
| Field display name | 字段在界面中显示的名称，比如「所在地区」「收货区域」。建议使用业务人员能直接理解的名称。 |
| Field name | 字段标识名称，用于 API、权限、工作流等内部引用。创建后通常不再修改。 |
| Field type | 字段在数据层的类型。通常存储为数组或字符串，按配置的层级保存省市区编码或名称。 |
| Selection level | 选择层级，可选只选省、省市两级、省市区三级。 |
| Value type | 值类型，可以选择保存行政区划名称或保存行政区划编码。 |
| Description | 字段说明。适合写选择要求说明。 |

> **注意**：行政区划数据由插件内置，会随版本更新同步最新的行政区划调整。

## 字段特性

| 特性 | 说明 |
|------|------|
| Field type | array 或 string，按配置决定 |
| 内置数据 | 预置中国省、市、区三级行政区划数据 |
| 页面组件 | 编辑模式使用级联选择器，按层级选择 |
| 筛选 | 支持按省、市、区筛选 |
| 排序 | 支持按地区名称排序 |
| 联动 | 选择省时动态加载对应市，选择市动态加载对应区 |

## 编辑配置

创建后，点击字段右侧的「Edit」可以编辑中国行政区字段配置。

| 配置 | 允许编辑 | 说明 |
|------|----------|------|
| Field display name | 是 | 修改字段显示名称。 |
| Field name | 否 | 字段标识创建后不建议修改。 |
| Selection level | 谨慎修改 | 修改层级后已有数据可能不完整。 |
| Value type | 谨慎修改 | 修改值类型（名称/编码）会影响历史数据展示。 |
| Description | 是 | 补充字段说明。 |

## 删除字段

点击字段右侧的「Delete」可以删除中国行政区字段。

> ⚠️ **警告**：删除字段会丢失所有已选择的地区数据，删除前确认是否需要迁移地址信息。

## 页面配置使用

中国行政区字段适合在表单中录入地址相关信息。

| 场景 | 用途 |
|------|------|
| 表单区块 | 级联选择省市区，常用于地址录入。 |
| 详情区块 | 展示完整的省市区名称。 |
| 表格区块 | 展示地区信息，支持按地区筛选排序。 |
| 统计图表 | 按省、市维度做数据统计分析。 |
