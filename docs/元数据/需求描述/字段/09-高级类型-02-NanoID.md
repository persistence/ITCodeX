# Nano ID

> 来源：NocoBase 文档整理
> 整理时间：2026-09-02

## 介绍

在 NocoBase 中，**Nano ID** 属于高级类型字段，用于生成短小、URL 安全的唯一字符串标识。

Nano ID 比 UUID 更短（默认 21 个字符），使用 URL 安全的字符集（A-Za-z0-9_-），同样具有极高的唯一性概率。适合在 URL 中使用，需要更短唯一标识的场景。

Nano ID 同样在创建记录时自动生成，不需要数据库自增序列。

## 适用场景

Nano ID 适合这些业务场景：

* URL 短链标识、分享链接 ID
* 邀请码、兑换码、访问令牌
* 前端路由中使用的记录 ID（比 UUID 更短更美观）
* 需要较短唯一标识的场景，不适合暴露自增 ID 的公开接口

## 创建配置

在数据表的「Configure fields」页面中，点击「Add field」，在高级类型中选择「Nano ID」可以创建 Nano ID 字段。

| 配置 | 说明 |
|------|------|
| Field interface | 字段的界面类型。Nano ID 对应 nanoid，自动生成只读。 |
| Field display name | 字段在界面中显示的名称，比如「短标识」「分享ID」。 |
| Field name | 字段标识名称，用于 API、权限、工作流等内部引用。创建后通常不再修改。 |
| Field type | 字段在数据层的类型。使用 varchar 存储，长度根据配置。 |
| Length | ID 长度，默认 21 字符，长度越短唯一性概率越低。 |
| Alphabet | 字符集，默认使用 URL 安全字符 `A-Za-z0-9_-`，可自定义。 |
| Auto fill | 新增记录时自动生成，默认开启。 |
| Description | 字段说明。 |

## 字段特性

| 特性 | 说明 |
|------|------|
| 默认长度 | 21 个字符，比 UUID（36字符）短约 42% |
| 字符集 | URL 安全，不需要转义，可以直接放在 URL 中 |
| 生成方式 | 加密安全的随机生成，重复概率极低 |
| 页面组件 | 只读展示，提供复制按钮 |
| 唯一性 | 默认 21 字符配置下，重复概率可以忽略，每秒生成 10 亿个 ID，需要约 35 万亿年才有 1% 概率重复 |
| 索引 | 建议建唯一索引 |

## 编辑配置

创建后，点击字段右侧的「Edit」可以编辑 Nano ID 字段配置。

| 配置 | 允许编辑 | 说明 |
|------|----------|------|
| Field display name | 是 | 修改字段显示名称。 |
| Field name | 否 | 字段标识创建后不建议修改。 |
| Length | 谨慎修改 | 修改长度只影响新生成的 ID，已有 ID 长度不变。长度过短增加碰撞风险。 |
| Alphabet | 谨慎修改 | 修改字符集只影响新生成的 ID，确保自定义字符集不包含 URL 特殊字符如果用于链接。 |
| Auto fill | 是 | 调整是否自动生成。 |
| Description | 是 | 补充字段说明。 |

> **注意**：缩短 ID 长度会增加碰撞概率，建议生产环境不要低于 12 字符。

## 删除字段

点击字段右侧的「Delete」可以删除 Nano ID 字段。删除会丢失所有已生成的短 ID，如果这些 ID 已经对外分享会导致链接失效。

## 页面配置使用

| 场景 | 用途 |
|------|------|
| 分享链接 | URL 中使用 Nano ID，链接更短更美观。 |
| 邀请码/兑换码 | 使用自定义字符集和更短长度，生成方便人工输入的编码。 |
| 详情页路由 | 前端详情页面路由参数，比 UUID 更短。 |
| API | 公开 API 使用 Nano ID 作为标识，避免自增 ID 泄露。 |

## Nano ID 与 UUID 对比

| 对比项 | UUID v4 | Nano ID (默认21字符) |
|--------|---------|---------------------|
| 长度 | 36 字符（含横杠） | 21 字符 |
| URL 安全 | 横杠安全，但比较长 | 完全 URL 安全，无需编码 |
| 生成速度 | 快 | 比 UUID 快约 2 倍 |
| 唯一性 | 极高 | 极高（21字符） |
| 存储大小 | 36 字节字符串 | 21 字节字符串 |
| 标准 | RFC 标准 | 事实标准，广泛使用 |

## 推荐长度选择

| 长度 | 场景 | 碰撞风险 |
|------|------|----------|
| 21 | 生产环境通用场景 | 忽略不计 |
| 16 | 一般业务场景 | 极低 |
| 12 | 内部系统、低并发场景 | 低 |
| 8 | 一次性令牌、测试环境 | 较高，不建议生产 |
