# Unix 时间戳（Unix timestamp）

> 来源：https://docs.nocobase.com/cn/data-sources/data-modeling/collection-fields/datetime/unix-timestamp
> 整理时间：2026-09-02

## 介绍

在 NocoBase 中，**Unix 时间戳（Unix timestamp）** 用于保存 Unix 时间戳数值。

Unix 时间戳字段适合系统交互、接口对接、日志时间、外部系统同步时间等场景。它存储的是从 1970-01-01 00:00:00 UTC 开始计算的秒数或毫秒数，页面展示时会转换为可读时间格式。

如果主要给用户录入和查看，选择日期或日期时间字段更方便。

## 适用场景

Unix 时间戳适合这些业务场景：

* 与外部系统交互的时间字段
* 日志时间、事件时间戳
* 接口同步时间、最后更新时间
* 以时间戳数值存储的系统时间

## 创建配置

在数据表的「Configure fields」页面中，点击「Add field」，选择「Unix 时间戳」可以创建Unix时间戳字段。

| 配置 | 说明 |
|------|------|
| Field interface | 字段的界面类型。Unix 时间戳对应 unixTimestamp，决定页面中如何录入和展示。 |
| Field display name | 字段在界面中显示的名称，比如「事件时间戳」「同步时间」「最后更新时间戳」。建议使用业务人员能直接理解的名称。 |
| Field name | 字段标识名称，用于 API、关系字段、权限、工作流等内部引用。创建后通常不再修改，只支持字母、数字和下划线，并且必须以字母开头。 |
| Field type | 字段在数据层的类型。Unix 时间戳通常使用 bigInt 或 integer，区分秒或毫秒。 |
| Unit | 时间戳单位，秒或毫秒。 |
| Display format | 展示格式，页面展示时把时间戳转换为可读日期时间格式。 |
| Default value | 默认值。可以选择当前时间戳或固定值。新增记录时，如果用户没有填写，可以自动带出默认值。 |
| Validation rules | 校验规则。可以配置数值范围或是否必填。 |
| Description | 字段说明。适合写字段含义、填写要求、数据来源或维护人。 |

> **注意**：字段名创建后会被页面区块、权限、工作流和 API 引用。创建前先确认命名，避免后续修改带来配置调整成本。

## 字段特性

| 特性 | 说明 |
|------|------|
| 默认 Field interface | unixTimestamp。 |
| 默认 Field type | bigInt。 |
| 可选 Field type | integer、bigInt。 |
| 页面组件 | 编辑模式可以按时间选择，保存为时间戳数值。 |
| 筛选 | 支持数值筛选和时间范围筛选，具体以界面配置为准。 |
| 排序 | 支持按时间戳数值排序。 |
| 存储 | 存储为整数或长整数，存储精度由单位决定。 |

## 编辑配置

创建后，点击字段右侧的「Edit」可以编辑Unix时间戳字段配置。编辑字段主要用于调整字段在 NocoBase 中的展示和使用方式，比如修改显示名称、说明、默认值、校验规则或展示格式。

如果字段来自主数据库中已经同步的表，编辑时通常是在做字段映射——把数据库字段映射为 NocoBase 的 Field type 和 Field interface。

| 配置 | 允许编辑 | 说明 |
|------|----------|------|
| Field display name | 是 | 修改字段在界面中的显示名称，不改变字段标识名称。 |
| Field name | 否 | 字段标识名称创建后通常不能在编辑表单中修改。 |
| Field interface | 条件支持 | 主数据库字段或同步字段在字段映射时可以调整。调整后会影响页面输入、展示和校验方式。 |
| Field type | 条件支持 | 主数据库字段或同步字段在字段映射时可以调整。调整前需要确认已有数据能否按新类型使用。 |
| Unit | 是 | 调整时间戳单位时要特别小心，避免秒和毫秒混用。 |
| Display format | 是 | 调整页面展示格式。 |
| Default value | 是 | 调整新增记录时的默认值。 |
| Validation rules | 是 | 调整字段校验规则。 |
| Description | 是 | 补充字段含义、填写要求、数据来源或维护人。 |

> **注意**：切换 Field type、时间单位或 Field interface 不等于简单改一个显示名称。它会影响字段的存储方式、数值含义、输入组件、校验规则、筛选条件和工作流变量使用方式。已有数据较多时，先确认数据格式是否匹配。

## 删除字段

点击字段右侧的「Delete」可以删除Unix时间戳字段。主数据库中还可以勾选多个字段后批量删除。

删除主数据库中新建的Unix时间戳字段时，通常会同时删除数据库中的真实列及该列已有数据。删除从数据库同步或外部数据源映射出的字段时，影响范围取决于对应数据源和字段来源。

> ⚠️ **警告**：删除字段可能影响页面区块、表单、筛选、权限、工作流、API、导入导出和已有数据。删除前先确认字段是否仍被业务配置引用。

## 页面配置使用

Unix 时间戳适合系统对接和技术场景，不建议作为用户直接理解的普通业务时间字段。

| 场景 | 用途 |
|------|------|
| API 对接 | 与外部系统交换时间戳数据。 |
| 系统日志 | 保存事件发生时间戳。 |
| 同步任务 | 记录最后同步时间戳。 |
| 页面展示 | 按可读时间格式展示给用户。 |
