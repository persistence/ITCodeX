# 几何多边形（Polygon）

> 来源：NocoBase 文档整理
> 整理时间：2026-09-02

## 介绍

在 NocoBase 中，**几何多边形（Polygon）** 属于几何图形字段，用于存储闭合的多边形区域，由多个点按顺序连接围成。

几何多边形字段用于表示不规则形状的区域，比如行政区划、服务范围、地块、建筑轮廓、围栏区域等。支持复杂多边形，可以包含孔洞（内环）。

## 适用场景

几何多边形适合这些业务场景：

* 行政区划、商圈、园区、地块边界
* 服务覆盖区域、销售区域划分
* 电子围栏、禁入区域
* 建筑轮廓、园区范围
* 规划区域、评估区域

## 创建配置

在数据表的「Configure fields」页面中，点击「Add field」，在几何图形类型中选择「多边形」可以创建几何多边形字段。

| 配置 | 说明 |
|------|------|
| Field interface | 字段的界面类型。多边形对应 polygon，用于在地图上绘制闭合区域。 |
| Field display name | 字段在界面中显示的名称，比如「服务区域」「行政区划」「地块范围」。 |
| Field name | 字段标识名称，用于 API、权限、工作流等内部引用。创建后通常不再修改。 |
| Field type | 字段在数据层的类型。多边形使用 polygon 空间类型。 |
| SRID | 空间参考标识符，默认 4326。 |
| Map provider | 地图服务商配置。 |
| Description | 字段说明。 |

## 字段特性

| 特性 | 说明 |
|------|------|
| Field type | polygon |
| 数据格式 | GeoJSON Polygon 格式，第一个点和最后一个点必须相同形成闭合，`{ "type": "Polygon", "coordinates": [[[lng1,lat1], [lng2,lat2], ..., [lng1,lat1]]] }` |
| 支持孔洞 | 支持外环+多个内环，形成带孔洞的复杂多边形 |
| 页面组件 | 地图绘制组件，点击加点绘制多边形边界，支持编辑节点 |
| 空间计算 | 支持面积计算、包含判断、相交判断、距离计算 |
| 展示 | 支持在地图上展示填充区域，可配置边框和填充样式 |

## 编辑配置

创建后，点击字段右侧的「Edit」可以编辑几何多边形字段配置。

| 配置 | 允许编辑 | 说明 |
|------|----------|------|
| Field display name | 是 | 修改字段显示名称。 |
| Field name | 否 | 字段标识创建后不建议修改。 |
| Map provider | 是 | 切换地图服务商。 |
| Polygon style | 是 | 配置边框颜色、填充颜色、透明度、线宽。 |
| Description | 是 | 补充字段说明。 |

## 删除字段

点击字段右侧的「Delete」可以删除几何多边形字段。删除会丢失所有区域数据。

## 页面配置使用

| 场景 | 用途 |
|------|------|
| 表单区块 | 点击地图绘制多边形区域，支持添加/删除节点、拖拽调整形状。 |
| 详情区块 | 地图展示绘制的多边形区域。 |
| 地图区块 | 批量展示多个区域，不同区域可设置不同颜色。 |
| 面积计算 | 自动计算多边形区域面积（平方米/平方公里/亩）。 |
| 空间判断 | 判断点位是否在区域内、区域是否相交。 |
| 筛选 | 按区域筛选落在区域内的记录。 |

## 注意事项

* 多边形必须闭合：第一个点和最后一个点坐标相同。
* 绕向规则：外环通常是逆时针方向，内环（孔洞）是顺时针方向，大多数空间数据库会自动处理。
* 复杂多边形支持多个孔洞，但在 UI 绘制通常先支持简单多边形。
