# 几何圆（Circle）

> 来源：NocoBase 文档整理
> 整理时间：2026-09-02

## 介绍

在 NocoBase 中，**几何圆（Circle）** 属于几何图形字段，用于存储圆形区域，由中心点坐标和半径定义。

几何圆字段用于表示服务范围、配送范围、搜索半径、围栏区域等圆形地理要素。适合门店服务范围、电子围栏、附近搜索半径等场景。

## 适用场景

几何圆适合这些业务场景：

* 门店配送范围、服务覆盖半径
* 电子围栏、签到打卡范围
* 附近搜索半径设置
* 影响范围、防护区域

## 创建配置

在数据表的「Configure fields」页面中，点击「Add field」，在几何图形类型中选择「圆」可以创建几何圆字段。

| 配置 | 说明 |
|------|------|
| Field interface | 字段的界面类型。圆对应 circle，用于在地图上绘制圆形区域。 |
| Field display name | 字段在界面中显示的名称，比如「配送范围」「服务半径」。 |
| Field name | 字段标识名称，用于 API、权限、工作流等内部引用。创建后通常不再修改。 |
| Field type | 字段在数据层的类型。由中心点 point 和半径 radius 组成。 |
| SRID | 空间参考标识符，默认 4326。 |
| Map provider | 地图服务商配置。 |
| Default radius | 默认半径，单位米/公里。 |
| Description | 字段说明。 |

## 字段特性

| 特性 | 说明 |
|------|------|
| 组成 | 中心点（经纬度）+ 半径（距离） |
| 半径单位 | 通常为米或公里，可配置 |
| 页面组件 | 地图绘制组件，中心点选点后拖拽调整半径大小 |
| 空间判断 | 支持判断点是否在圆内（位置是否在服务范围内） |
| 展示 | 支持在地图上展示圆形填充区域，可配置颜色、透明度 |

## 编辑配置

创建后，点击字段右侧的「Edit」可以编辑几何圆字段配置。

| 配置 | 允许编辑 | 说明 |
|------|----------|------|
| Field display name | 是 | 修改字段显示名称。 |
| Field name | 否 | 字段标识创建后不建议修改。 |
| Map provider | 是 | 切换地图服务商。 |
| Default radius | 是 | 修改默认半径。 |
| Circle style | 是 | 配置填充颜色、边框颜色、透明度。 |
| Description | 是 | 补充字段说明。 |

## 删除字段

点击字段右侧的「Delete」可以删除几何圆字段。删除会丢失所有圆形区域数据。

## 页面配置使用

| 场景 | 用途 |
|------|------|
| 表单区块 | 选择中心点，拖拽调整半径大小绘制圆形区域。 |
| 详情区块 | 地图展示圆形服务范围。 |
| 地图区块 | 批量展示多个圆形范围。 |
| 业务判断 | 判断用户位置是否在配送范围内、签到点是否在围栏内。 |
| 筛选 | 筛选圆形范围内包含的点位记录。 |
