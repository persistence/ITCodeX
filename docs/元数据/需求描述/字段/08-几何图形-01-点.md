# 几何点（Point）

> 来源：NocoBase 文档整理
> 整理时间：2026-09-02

## 介绍

在 NocoBase 中，**几何点（Point）** 属于几何图形字段，用于存储单个地理坐标点，使用经纬度表示位置。

几何点字段基于数据库的空间扩展（如 PostGIS、MySQL Spatial）存储，可以在地图组件中标记位置，支持空间查询（如附近搜索、范围内查找）。适合门店位置、用户定位、事件发生地点等单个点位场景。

使用几何字段需要数据库支持空间数据类型，推荐使用 PostgreSQL + PostGIS。

## 适用场景

几何点适合这些业务场景：

* 门店位置、仓库位置、服务网点坐标
* 用户定位、签到位置、事件发生地点
* 设备位置、资产位置标记
* POI（兴趣点）位置存储

## 创建配置

在数据表的「Configure fields」页面中，点击「Add field」，在几何图形类型中选择「点」可以创建几何点字段。

| 配置 | 说明 |
|------|------|
| Field interface | 字段的界面类型。点对应 point，用于在地图上选点。 |
| Field display name | 字段在界面中显示的名称，比如「门店位置」「签到位置」。建议使用业务人员能直接理解的名称。 |
| Field name | 字段标识名称，用于 API、权限、工作流等内部引用。创建后通常不再修改。 |
| Field type | 字段在数据层的类型。几何点使用 point 空间类型。 |
| SRID | 空间参考标识符，默认是 4326（WGS84 经纬度坐标系），用于 GPS 和地图。 |
| Map provider | 地图服务商配置，可以选择高德、百度、OpenStreetMap 等。 |
| Description | 字段说明。适合说明坐标要求。 |

## 字段特性

| 特性 | 说明 |
|------|------|
| Field type | point |
| 坐标系 | 默认 WGS84 (SRID 4326)，支持其他坐标系配置 |
| 数据库要求 | 需要支持空间数据类型，推荐 PostgreSQL + PostGIS |
| 页面组件 | 地图选点组件，支持搜索地址、拖拽选点、点击选点 |
| 数据格式 | 标准 GeoJSON Point 格式，`{ "type": "Point", "coordinates": [经度, 纬度] }` |
| 空间查询 | 支持距离计算、附近查找、包含判断等空间查询 |
| 展示 | 支持在地图上展示点位标记 |

## 坐标格式

几何点使用经纬度表示：

* **经度 (Longitude)**：范围 -180 到 180，东经为正，西经为负
* **纬度 (Latitude)**：范围 -90 到 90，北纬为正，南纬为负
* 存储顺序：GeoJSON 规范是 **[经度, 纬度]**（先经后纬）

## 编辑配置

创建后，点击字段右侧的「Edit」可以编辑几何点字段配置。

| 配置 | 允许编辑 | 说明 |
|------|----------|------|
| Field display name | 是 | 修改字段显示名称。 |
| Field name | 否 | 字段标识创建后不建议修改。 |
| Map provider | 是 | 切换地图服务商。 |
| SRID | 否 | 坐标系创建后不能修改，会影响已有数据。 |
| Description | 是 | 补充字段说明。 |

## 删除字段

点击字段右侧的「Delete」可以删除几何点字段。

> ⚠️ **警告**：删除字段会丢失所有点位坐标数据，删除前确认位置数据已备份。

## 页面配置使用

几何点字段结合地图组件使用。

| 场景 | 用途 |
|------|------|
| 表单区块 | 地图选点，支持地址搜索定位、手动点击选点、拖拽调整位置。 |
| 详情区块 | 地图展示点位，显示标记。 |
| 表格区块 | 显示经纬度或缩略地图。 |
| 地图区块 | 所有点位在地图上批量展示，支持点击查看详情。 |
| 筛选 | 支持按坐标范围筛选、附近N公里内查找。 |

## 注意事项

1. **数据库支持**：MySQL 5.7+、PostgreSQL + PostGIS 支持空间类型，SQLite 支持有限。
2. **坐标系转换**：国内地图（高德、百度）使用不同坐标系，需要注意转换：
   - WGS84：国际通用坐标系，GPS 原始坐标，Google Earth、OpenStreetMap 使用
   - GCJ-02：国测局坐标系，高德地图、腾讯地图使用
   - BD-09：百度坐标系，百度地图使用
3. **经度纬度顺序**：注意 GeoJSON 是 [经度, 纬度]，不要搞反顺序。
